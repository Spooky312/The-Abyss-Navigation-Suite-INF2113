## Quality Control Provider

### Company Name
**Veridion Systems Validation Labs**

### Role
Independent **Quality Control (QC)** authority responsible for verification and validation of the developed system.

### Company Overview
Veridion Systems Validation Labs is an independent testing and validation organisation specialising in verification of mission-critical software systems. The organisation provides structured system testing, validation, and operational verification to confirm that delivered software satisfies the functional and non-functional requirements defined in the SRS.

### Responsibilities

- Conduct system-level testing of the delivered software.
- Perform integration and acceptance testing.
- Validate system behaviour against specified functional requirements.
- Verify compliance with defined performance and reliability criteria.
- Document and report verification results.
- Provide independent validation reports for system acceptance.
